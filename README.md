# 记得 · 第一版 PWA

功能：
- 中文快速记事：明天 / 后天 / X天后 / X周后 / X月后
- 周期事项：每X天 / 周 / 月重复
- 首页倒计时
- 猫咪用品与周期事项
- 一键导出 .ics，可导入 iPhone 日历
- 支持添加到 iPhone 主屏幕（部署到 HTTPS 后）
- 数据当前保存在本机浏览器 localStorage

iPhone 使用建议：
1. 将整个目录部署到任意 HTTPS 静态站点。
2. 用 Safari 打开。
3. 分享 → 添加到主屏幕。
4. 重要事项点击“加到日历”，作为系统级提醒兜底。

注意：
- 纯网页不能直接写入 Apple「提醒事项」数据库。
- 若需要真正联动「提醒事项」，下一版建议增加 iPhone 快捷指令或原生 iOS 壳。
「记得」V2 更新说明

版本定位：iPhone 兼容增强版

# 记得 · 第二版 PWA

V2 主要针对 iPhone 使用体验进行了优化，让「记得」从普通网页进一步接近独立 App 的使用方式。

主要更新包括：

增加 Apple Touch Icon，添加到 iPhone 主屏幕后可显示独立应用图标；
完善 PWA 配置，支持以 独立 App 模式 打开；
优化 iPhone Safari 的主屏幕安装兼容性；
增加 192×192、512×512 应用图标；
更新 Manifest 配置，补充应用名称、启动方式、屏幕方向等信息；
升级 Service Worker 缓存机制，减少打开旧版本页面的问题；
增加 iPhone 端“添加到主屏幕”的安装提示；
保留原有核心功能，包括快速记事、倒计时、周期事项、猫咪用品管理及日历导出。

V2 的核心目标：

让「记得」在 iPhone 上真正具备接近 App 的使用体验，能够从桌面独立启动，方便随手记录和查看提醒。

# 记得 · 第三版 PWA

版本定位：火车票提醒版

V3 在 V2 的基础上新增了专门的 火车票购票提醒模块，进一步增强生活场景中的时间提醒能力。

主要更新包括：

新增 “火车票”独立入口；
支持填写 出发站、到达站、出发日期；
默认按照 15 天预售期自动计算预计购票日期；
支持手动调整预售期，便于后续规则变化时继续使用；
支持填写车站具体 起售时间；
支持 往返行程，可同时生成去程和返程购票提醒；
首页自动展示即将到来的购票事项；
支持一键将购票提醒加入 iPhone 日历；
日历提醒支持提前提醒和开售时提醒；
优化首页结构，形成：
记一件事｜火车票｜猫咪
三个主要入口；
延续并兼容原有待办和猫咪管理数据。

V3 的核心目标：

从“记住一件事”进一步升级为“根据日期自动帮你算出什么时候该做”，减少自己计算购票日和反复记时间的负担。
